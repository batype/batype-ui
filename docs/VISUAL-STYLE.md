# 视觉规范与宿主兼容

本轮样式以来源后台的紧凑布局、实色操作按钮、填充式输入框及圆角斑马纹表格为基准。组件库保持独立，不依赖 HeroUI、Tailwind 或业务 SDK。

## 尺寸

| 控件                                                                        | comfortable    | compact        |
| --------------------------------------------------------------------------- | -------------- | -------------- |
| 默认 Button、Input、Select、SearchSelect、NumberInput、DatePicker、Dropdown | 40px           | 32px           |
| Button / ActionButton `sm`                                                  | 32px           | 32px           |
| Button / ActionButton `lg`                                                  | 48px           | 48px           |
| Pagination 按钮、页大小选择                                                 | 32px           | 32px           |
| Checkbox / Switch                                                           | 20px / 40×24px | 20px / 40×24px |

以上是最小高度；多行内容允许自然增高，避免文字被裁切。默认字号14px、紧凑模式12px，表格正文14px、表头12px。工具栏应使用同一密度，不混用固定大号按钮与紧凑输入框。

## 层级与颜色

- 主要操作使用蓝色实色按钮，普通操作使用灰色实色按钮；ActionButton 默认实色，可显式指定 soft、outline、ghost。
- 绿色、黄色、粉红色保留语义；实色背景文字和浅色背景文字分别使用 `--bui-*-text`、`--bui-*-ink`，避免成功/警告标签看不清。
- 圆角、边框、表面与轻阴影使用统一令牌。表格保留40px表头、8px上下留白、完整斑马纹与无行分隔线；手机使用紧凑卡片。
- 表格操作建议直接返回按钮 Fragment，或使用 `className="bui-action-group"` 的容器，确保窄屏允许换行。组件库不猜测宿主布局类名。

## 样式隔离

导入 CSS 不应改变宿主输入框和按钮的字体、字号、行高或焦点规则。重置和焦点样式只作用于库自身的类名；UIProvider 继承宿主行高，库控件显式声明自身排版。

宿主需要自己的配色时，通过 UIProvider 的 tokens 设置 `--bui-*` 变量。深浅色、system和紧凑密度均可使用同一套组件。覆盖基础语义色时，也应配套设置 `*-text`、`*-soft`、`*-ink`，保证不同变体可读。

## 验收

UIProvider 演示页提供浅色/深色 × 标准/紧凑的同屏对照。浏览器回归检查高度、按钮与标签对比度、宿主样式隔离、焦点、表格与手机溢出；现有表单、弹窗、编辑器交互测试继续保留。

本次仅调整视觉与 ActionButton 的默认 variant，未改变业务回调、受控状态、权限或数据接口。已有项目的自定义适配层可逐步简化，应先验证再移除，不应一并删除旧组件。
